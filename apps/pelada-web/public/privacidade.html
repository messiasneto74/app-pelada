Política de privacidade

O app Pelada organiza partidas, presença e sorteio de times. Não vendemos dados pessoais.

Dados coletados

Dado Finalidade
Conta (nome, e-mail) via Keycloak Login e identificação
Telefone (quando solicitado) Contato do organizador
Pelada, jogadores, partidas Funcionalidade do app
Fotos enviadas Exibição no elenco

Dados ficam na API e PostgreSQL do operador. Autenticação via OpenID Connect (Keycloak); a API valida JWT e não armazena senhas do IdP no app.

Versão completa e contato: ver documentação no repositório e e-mail de suporte configurado na ficha da loja após deploy staging.
