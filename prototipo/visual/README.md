# Resenha — galeria de telas

Capturas reais do protótipo no Chromium. Clique nas imagens para abrir em tamanho original.

**Celular:** 390 × 844 px, com toque e dispositivo móvel emulado. **Desktop:** 1440 × 1000 px. As telas completas incluem o conteúdo abaixo da dobra; os formulários são capturados no tamanho da janela.

Os dados são demonstrativos. Cada formato usa uma sessão isolada, por isso os times sorteados podem variar.

## Reproduzir os prints

Em `prototipo/`, execute `npm ci` e `npm run screenshots`. Requer Python 3, Chromium e porta 8002 livre. O script usa Chromium do sistema quando disponível ou `CHROMIUM_PATH`; alternativamente instale com `npx playwright install chromium`.
